# Shape React + Tailwind Replica

A component-based React recreation of the supplied agency website reference.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints in your terminal (normally `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Main components

- `Header.jsx`
- `Hero.jsx`
- `About.jsx`
- `Work.jsx` + `ProjectCard.jsx`
- `Expertise.jsx`
- `Testimonial.jsx`
- `Sharing.jsx`
- `Marquee.jsx`
- `AiSection.jsx`
- `Footer.jsx`
- `FloatingBadge.jsx`

All styling is Tailwind CSS, with only a few global animation/base rules in `src/index.css`.
